# F04 — Acceptance Criteria

E2E tests use two Clerk test users A and B (`E2E_USER_A_*`, `E2E_USER_B_*`) with one `browser.newContext()` each; projects are created via the `createProject` action in `beforeEach` through a test-only helper page or by driving the UI, and cleaned up in `afterEach`.
