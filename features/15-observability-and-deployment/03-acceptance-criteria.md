## M1 acceptance run script (AC-027)

Preconditions: production (or the `main` preview alias) deployment of the release candidate commit; `npm run check` green in CI on that commit (step 8); two Clerk accounts A and B; both browsers with console open and "Preserve log" enabled; screenshots saved under `docs/acceptance/m1/<commit>/`.

| Step | Actor(s) | Action | Expected | Evidence (screenshot / log path / commit) | Pass/Fail |
|---|---|---|---|---|---|
| 1 | A, B | A creates project "M1 run"; B opens its URL. | B sees the AccessDenied view; no project name leaked; `GET /api/projects/{id}/canvas` as B → 403. | `01-b-denied.png`, curl status | |
| 2 | A, B | A invites B's email as editor; B opens the project. | B's "Shared with me" lists it; workspace opens with empty canvas. | `02-b-open.png` | |
| 3 | A, B | Both add, move, resize, recolour, label, and connect nodes (≥ 2 nodes + 1 edge each). | Each sees the other's change < 1 s; both cursors with name badges visible; avatar stack shows 2. | `03-a.png`, `03-b.png`, short screen recording path | |
| 7 | A | A imports a starter template (confirmation dialog → confirm). | Canvas replaced for both; B sees the template; `CANVAS_REPLACED` noted in B's UI if F14 shows one. | `07-template-both.png` | |
| 4 | A | A undoes their last change (⌘/Ctrl-Z). | Only A's change reverts; B's nodes unchanged; both converge. | `04-undo.png` | |
| 5 | A, B | B reloads; A closes the tab, waits ≥ 60 min (or, with owner's agreement, ≥ 1 autosave interval + room eviction simulated by `deleteStorageDocument` on a copy), reopens. | Identical node/edge count and positions after B's reload and after A's reopen (snapshot restore). | `05-b-reload.png`, `05-a-reopen.png`, counts in table | |
| 6 | A, B | A changes B to viewer; B tries to drag a node. A removes B. | B cannot modify (UI hides affordances; drag no-op); B is ejected within 5 s and reopening shows AccessDenied; `/api/liveblocks-auth` as B → 403. | `06-viewer.png`, `06-kicked.png`, timing | |
| 8 | A | Review both consoles; open CI for the deployed commit. | Zero console errors (warnings listed and justified); `npm run check` and `build` green on the commit. | console export files, CI run URL, commit SHA | |

Rules: a Fail on any step stops M1 sign-off (EC-017); after the fix, the whole script is re-run on the new commit. The completed table is copied into `status.md` under "M1 acceptance run evidence" with the commit hash and date.
