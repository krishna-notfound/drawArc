## UX and interaction behaviour

- **Palette**: eight items, a 1 px `border-surface-border` divider between the shapes and the two whiteboard items; icons `h-5 w-5`; compact variant under 768 px per F07.
- **Text node at rest**: Geist Sans at `TEXT_SIZE_PX[size]` (12/14/20/28), line-height 1.3, padding 4 px 6 px, `font-weight 600` when bold, `text-align` from `align`; min visible box 24 × 20. Auto-width nodes keep `white-space: pre` so a ±1 px font-rendering difference on another OS never wraps a line.
- **Text editor**: textarea overlay with identical typography; grows per keystroke using the mirror (auto-width: width and height; fixed-width: height only); caret at end, all selected on open (F08).
- **Sticky**: padding 12 px, text top-left by default, wraps, `overflow: hidden` beyond the box; shadow only on sticky (text nodes and shapes unchanged).
- **Toolbar**: F08's single properties toolbar above the selection (colour · border · text size · bold · align — F08 FR-024); F22 adds nothing to it.
- **Copy**: placeholders "Text" (text kind, editors only, as F08's ruling) and "Double-click to label" (sticky); toolbar copy is F08 FR-024.
- **Keyboard**: `t`/`n` create; everything else is F08/F10. Keys are matched on `event.key` lower-cased with no modifier, so `Ctrl+T`/`Ctrl+N` reach the browser.

## Error handling and edge cases

| ID | Condition | Expected behaviour | Covered by |
|---|---|---|---|
| EC-001 | v1 snapshot in Blob, room empty, user opens project | Seed path migrates to v2 and validates; nodes render identically (same positions, sizes, colours); `canvasSchemaVersion` becomes 2 after the next successful PUT | AC-001, AC-006 |
| EC-002 | Document stores `schemaVersion: 3` (newer app) | Returned unchanged by `migrate`, rejected on `schemaVersion` → F13 `SNAPSHOT_INVALID` warning path, unchanged behaviour | AC-001 |
| EC-003 | Remote data contains `color: '#757575'` (fill at the worst-case luminance ≈ 0.18) | Rendered with black text at ≥ 4.58:1 (pure-pair guarantee, F08 D-08g); no refusal path exists for filled kinds. A `text` node whose hex fails against `--bg-base` is still rendered; only the F08 v2 hex input refuses it (`textContrastOk('text', hex)`) | AC-004 |
| EC-004 | Edge references a text node (hand-crafted or newer client) | Rejected by Zod at every persistence boundary; at runtime a text node has no handles so `onConnect` never fires for it | AC-005 |
| EC-005 | Fonts not yet loaded when the first text commit happens | Measurement awaits `document.fonts.ready` (resolved immediately after first load); committed size uses the real font | AC-010 (unit: measurer awaited) |
| EC-006 | Storage holds a `frame` or `image` node written by a newer client | `ReservedKindNode` placeholder, no crash, deletable, excluded from toolbars | AC-017 |
| EC-007 | User presses T, types nothing, clicks elsewhere / presses Escape | Node deleted (FR-013); two undo entries (add, delete); undoing the delete restores an empty node that shows the "Text" placeholder, so it is never invisible | AC-013 |
| EC-008 | A and B commit different labels on the same text node | Last writer wins per key (D-014); the loser's `width`/`height` may be overwritten with the winner's measured size, which matches the winning label — consistent | AC-012 (documented), F08 AC-021 pattern |
| EC-009 | B deletes a text node while A is typing | F08 FR-010 path: editor unmounts, no commit, no resurrect, no auto-delete call for a missing node (`nodeLookup` miss → no-op) | AC-012 |
| EC-010 | 500-character paste into a text node | `maxLength=500` in the textarea; stored ≤ 500; width grows to the longest line, height to line count; still one write | AC-010 |
| EC-011 | Resize a sticky below 75 × 75 or a text node below 24 px wide | Clamped by `NodeResizer`; Zod `min` per kind rejects anything smaller from other sources | AC-011, AC-003 |
| EC-012 | Multi-selection mixes a shape and a sticky | One F08 properties toolbar for both (both kinds are in `TEXT_OPTION_KINDS`); differing values show the "—" mixed badge (F08 FR-024); a selection containing a reserved-kind placeholder hides the text groups | AC-016 |
| EC-013 | `t` pressed while the F08 editor or a dialog is open | Ignored (`isEditableTarget` / `hasOpenOverlay`); no node created | AC-008 |
| EC-014 | Viewer presses T/N or calls `window.__canvasMutations.addNodeOfKind` | No change locally or remotely | AC-018 |
| EC-015 | Hex colour `#FFF` (3 digits) or `rgb(…)` in remote data | Rejected by Zod (`#rrggbb` only); runtime `resolveColor` falls back to `neutral` with one `console.warn` | AC-002, AC-004 |
